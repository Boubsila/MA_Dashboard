Quick guide

Navigate without the guesswork

Everything is clickable. Filters apply to the whole dashboard: KPIs, charts and tables at once.

Read this once, then work without asking. Every figure on this page is clickable and every filter is shared by all views. This guide explains what each view contains, how filters combine, how to refresh the data and how the Snapshot button writes into data/ma_snapshot.js.
1 · The workspace in 30 seconds
1

MA or Extra

MA is the operational Koop scope: Captive, Non-captive and Unclassified lines. Extra holds everything you may need to check next to it: claims, suppliers, BB, MAAK and lines without supplier. The counter on each tab is the number of lines it contains.

2

The side rail opens a view

Each item swaps the card on the right without reloading the page. The active item keeps an accent bar. On a phone the rail scrolls sideways.

3

The filter bar is global

Set a filter once: KPIs, charts and every table follow it immediately. The line under the bar tells you how many lines remain and which filters are active.

4

Drill down by clicking

Click a KPI card, a chart slice, a legend item or a bar: the matching filter is applied and, for Pots or Claims, the right view opens.

3 · Filters, one by one
SearchFree text on reference, item, description and supplier.
CategoryCaptive, Non-captive or Unclassified.
NatureDirect or Pot (2828).
Due dateLate / stagnant, ≤ 30 days, > 30 days, no date.
MA age0-7 d, 7-10 d, > 10 d, or no creation date.
UsageVOR (bus stopped), BO (back order), Stock, ABC, other.
SupplierOne supplier code, with its open-line count.
PeriodNext 30 or next 60 days.
Filters combine with AND: Category = Captive plus Due = Late shows only captive lines that are late. Active filters appear as chips under the bar: click × to remove one, or Clear all / Reset to start over.
4 · Tables: sort and page
↕

Sort a column

Click a column header once for ascending, again for descending. The arrow in the header shows the active sort.

↔

Move through pages

Use « ‹ › » under the table. The centre shows the current page and the filtered line count. Tables show up to 50 lines per page and add pager buttons when there are more.

Horizontal scrolling stays inside the table: the page itself never slides sideways.

5 · Refresh the data
A

Reload your Excel files

Reload accepts .xlsx, .xlsm and .txt. The MA sheet must contain the BB-NUMMER and LVRCR columns; the reference table feeds Captive / Non-captive and the creation-date file feeds MA age. A snapshot is updated right after a successful import.

B

Snapshot replaces data/ma_snapshot.js

The button saves the full dataset currently loaded (filters are not baked in), stamps it with the date and time, and replaces the existing file in the data folder. No download, no copy-paste.

  • Launched with MA Pilotage.cmd: the local server writes the file instantly. The badge shows auto-save.
  • Opened as a plain HTML file: Chrome or Edge asks for the data folder once. Afterwards every click replaces the file silently; the badge shows folder linked.
  • Other browsers: when direct writing is impossible, the file is downloaded and you place it in data/. Use Chrome or Edge to avoid this.
The dashboard keeps a local copy in the browser. On start-up it uses whichever is newer: that local copy or data/ma_snapshot.js. Replacing the snapshot file therefore takes effect on the next reload.
6 · Rules behind the figures
  • MA reference = 8 characters.
  • BB reference = 9 characters (informational).
  • Pot = 2828.
  • Claims = references starting with MC or MV.
  • MAAK = code below 100 (informational).
  • Captive / Non-captive comes from the reference table; an unknown reference stays Unclassified.
  • Due date, MA age and priority are recalculated every time the page opens.
7 · Troubleshooting
The dashboard shows data older than the file

The browser cache was newer on start-up. Click Snapshot to write the displayed data, or use Reload to import the files again. The newest of the cache and data/ma_snapshot.js wins on load.

Snapshot downloads a file instead of writing it

The page is open in a browser without folder access (Firefox, Safari) or the folder permission was refused. Open the dashboard with MA Pilotage.cmd, or retry in Chrome / Edge and authorise the data folder once.

“No data” at start-up

data/ma_snapshot.js is missing or empty. Run node tools/build_snapshot.js, or use Reload with your Excel files.

A filter hides everything

Look at the chips under the filter bar: two filters may contradict each other. Click Reset to clear them all.

The figures differ from my Excel total

KPIs only cover the Koop scope: BB, MAAK and lines without supplier are excluded by design. Check the footer for the exact rules.

How do I reset my local copy?

Import your files again with Reload, or take a new snapshot. The local copy is then replaced by the data you see.
